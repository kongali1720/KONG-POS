# Contributing to KONGALIPOS

Thank you for your interest in contributing to **KONGALIPOS**! Whether it's bug fixing, improving terminal simulation logic, or enhancing documentation, contributions are always welcome.

## 🔄 Development Workflow

1. **Fork the Repository**
2. **Create your Feature Branch:**
   ```bash
   git checkout -b feature/AmazingFeature
   ```
3. **Commit your Changes:**
   ```bash
   git commit -m "feat: add amazing terminal feature"
   ```
4. **Push to the Branch:**
   ```bash
   git push origin feature/AmazingFeature
   ```
5. **Open a Pull Request**

## 💡 Code Standards
* Follow clean architecture principles and maintain clear variable/endpoint naming.
* Test your changes locally before submitting a pull request.
